# P0-005 — 基础应用设置

## Goal

实现基础的应用设置页面，允许用户配置应用基本参数。

## Background

P0-004 完成后，需要实现设置页面以完成 Phase 0 的基础功能。

## Scope

- 创建 Settings 页面组件
- 实现基础设置项：
  - 应用名称配置
  - 主题颜色选择（浅色/深色）
  - 语言设置（中文/英文）
- 使用 Pinia 管理设置状态
- 设置持久化到 localStorage

## Out of Scope

- 高级设置
- 代理配置
- AI Provider 配置
- 数据库连接设置
- 用户账户系统

## Dependencies

- t_4933fa5a (P0-004: Dashboard 空状态页面) - 待完成

## Acceptance Criteria

1. Settings 页面可正常访问
2. 设置项可保存并持久化
3. 刷新页面后设置保持
4. 主题切换生效
5. 无运行时错误

## Definition of Done

- [ ] Settings 页面实现完成
- [ ] 设置持久化功能完成
- [ ] Build 成功
