# P0-004 — Dashboard 空状态页面

## Goal

创建 Dashboard 页面的空状态 UI，展示平台核心功能入口。

## Background

P0-003 完成后，需要实现 Dashboard 页面的视觉呈现。

## Scope

- 实现 Dashboard 首页组件
- 展示空状态（无数据时的友好提示）
- 添加平台核心功能卡片/入口：
  - Agent 管理
  - Account 管理
  - Settings
- 使用简洁的图标和文字说明
- 响应式网格布局

## Out of Scope

- 真实数据展示
- 图表可视化
- 复杂交互功能
- 后端 API 对接

## Dependencies

- t_5ad2165a (P0-003: 基础路由) - 待完成

## Acceptance Criteria

1. Dashboard 页面正常显示
2. 功能卡片布局整齐美观
3. 点击卡片可跳转到对应页面（或显示 TODO 提示）
4. 空状态提示清晰友好
5. 无控制台错误

## Definition of Done

- [ ] Dashboard 组件实现完成
- [ ] 功能卡片 UI 完成
- [ ] Build 成功
- [ ] QA 验收通过
