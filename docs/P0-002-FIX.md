# P0-002-FIX — 修复 Layout 重复渲染问题

## Goal

修复 P0-002 中 AppLayout 重复渲染导致的双 Sidebar 问题，确保 Layout 结构正确。

## Background

用户反馈实际运行时发现两个问题：
1. 页面出现两个重复的 Sidebar
2. 主内容区域没有形成正式的应用 Layout

根本原因：App.vue 和 router/index.ts 都引入了 AppLayout 组件，导致双重嵌套渲染。

## Scope

### 需要修复的内容

1. **修复 App.vue**
   - 移除对 AppLayout 的直接引用
   - 改为直接使用 RouterView
   - 确保全局样式正确引入

2. **检查路由配置**
   - 确认 AppLayout 只在 router 中定义一次
   - 确保所有页面都通过 AppLayout 渲染

3. **修复 Layout 结构**
   - 确保 Sidebar 只出现一次
   - 确保主内容区域正确占满剩余空间
   - 确保 Design Token 正确应用到各组件

4. **验证构建**
   - npm run build 成功
   - npm run type-check 无错误

### 不需要修改的内容（Out of Scope）

- 不实现 P0-003 的新业务功能（路由守卫、动态路由等）
- 不实现 P0-004 的新页面（Dashboard 功能卡片等）
- 不实现 P0-005 的新功能（Settings 持久化等）
- 保留现有 Sidebar.vue 和 AppLayout.vue 核心逻辑
- 保留现有所有 View 组件

## Acceptance Criteria

1. ✅ 页面只有一个 Sidebar
2. ✅ 页面只有一个 AppLayout
3. ✅ 主内容区域正确占满剩余空间（不是默认 HTML 风格）
4. ✅ Sidebar 导航视觉统一（使用 Design Token）
5. ✅ 页面不是浏览器默认 HTML 风格
6. ✅ Vite dev 页面正常
7. ✅ Build 成功（npm run build）
8. ✅ TypeScript 类型检查通过（npm run type-check）

- [ ] 验证主内容区正确渲染
