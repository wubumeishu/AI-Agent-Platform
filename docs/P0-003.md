# P0-003 — 基础路由

## Goal

配置应用的基础路由结构，实现页面间的导航切换。

## Background

P0-002 完成后，需要配置路由使各页面可以正常跳转。

## Scope

- 配置 Vue Router 路由表
- 创建以下路由页面结构：
  - / (Dashboard)
  - /settings (设置页面)
- 实现路由守卫（基础权限检查）
- 配置 404 页面

## Out of Scope

- 动态路由
- 路由懒加载优化
- 路由动画效果
- 权限系统实现

## Dependencies

- t_100d059e (P0-002: 应用 Layout) - 待完成

## Acceptance Criteria

1. 访问 / 显示 Dashboard 页面
2. 访问 /settings 显示设置页面
3. 访问不存在的路由显示 404 页面
4. 导航栏点击可正确跳转
5. 浏览器前进/后退按钮正常工作

## Definition of Done

- [ ] 路由配置完成
